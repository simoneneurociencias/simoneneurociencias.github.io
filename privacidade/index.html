Política de Privacidade

Simone Carneiro Neurociência · Última atualização: 31 de agosto de 2026

Esta política explica quais dados são coletados nas páginas e nos aplicativos mantidos por Simone Carneiro Neurociência, para que servem, por quanto tempo ficam guardados e como pedir a exclusão deles.

Quem é responsável pelos dados

Simone Carneiro, profissional de hipnoterapia e neurociência aplicada, responsável pelo perfil @sicarneironeurociencia no Instagram e pelas páginas publicadas neste site.

Dados coletados nas páginas deste site

Quando alguém preenche um formulário de inscrição ou responde a um questionário de autoavaliação, são coletados os dados informados voluntariamente no próprio formulário:

  • Nome
  • E-mail
  • Número de WhatsApp
  • As respostas dadas ao questionário, quando houver
  • A origem do acesso, ou seja, por qual link a pessoa chegou até a página

Esses dados são usados para enviar o material solicitado, dar acesso ao evento em que a pessoa se inscreveu e enviar comunicações relacionadas a esses conteúdos. Ficam armazenados em planilha de uso restrito, acessível apenas pela responsável.

Dados tratados no aplicativo de atendimento do Instagram

É usado um aplicativo próprio, integrado à API oficial da Meta, para organizar o atendimento do perfil @sicarneironeurociencia. Ele funciona assim:

  • Lê os comentários públicos feitos nas publicações do próprio perfil, para identificar quem pediu um material específico.
  • Responde ao comentário publicamente e envia por mensagem direta o link do material que a pessoa pediu.
  • Lê as mensagens recebidas na caixa de entrada do perfil, para responder a quem escreveu.

O aplicativo nunca inicia conversa com quem não interagiu antes. Uma mensagem só é enviada em resposta a um comentário ou a uma mensagem que a própria pessoa enviou, conforme as regras da plataforma.

O conteúdo dos comentários e das mensagens não é copiado para banco de dados nem usado para montar listas. O aplicativo guarda apenas o identificador técnico de cada comentário e de cada conversa já respondida, e serve só para não enviar a mesma resposta duas vezes para a mesma pessoa. Esse registro fica no computador da responsável, não é compartilhado e pode ser apagado a qualquer momento.

Com quem os dados são compartilhados

Os dados não são vendidos, alugados nem cedidos para terceiros com finalidade comercial. São usados os seguintes serviços de apoio, cada um com política de privacidade própria:

  • Meta, para o funcionamento do Instagram e da API oficial de atendimento
  • Google, para armazenamento das planilhas de inscrição
  • GitHub Pages, para hospedagem destas páginas
  • Eduzz, para processamento de pagamentos, quando houver compra

Por quanto tempo os dados ficam guardados

Os dados de inscrição são mantidos enquanto durar o relacionamento com a pessoa e por até cinco anos depois do último contato, prazo usado para fins de registro. Os identificadores técnicos do aplicativo de atendimento são apagados sempre que o histórico é limpo.

Direitos de quem forneceu os dados

Conforme a Lei Geral de Proteção de Dados, qualquer pessoa pode solicitar, a qualquer momento e sem custo:

  • Confirmação de que existem dados dela armazenados
  • Acesso aos dados
  • Correção de dados incompletos ou desatualizados
  • Exclusão dos dados
  • Cancelamento do envio de comunicações

Como pedir exclusão dos dados

Basta enviar uma mensagem direta para @sicarneironeurociencia no Instagram, pedindo a exclusão. O pedido é atendido em até 15 dias, e a pessoa recebe a confirmação por resposta na mesma conversa.

Cookies

Estas páginas não usam cookies de rastreamento nem de publicidade. É usado apenas o armazenamento local do navegador, e somente para lembrar por qual link a pessoa chegou até a página durante a mesma visita.

Mudanças nesta política

Esta política pode ser atualizada. Quando isso acontecer, a data no topo da página é alterada. Recomenda-se conferir esta página periodicamente.
